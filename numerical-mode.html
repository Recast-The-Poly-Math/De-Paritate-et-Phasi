From Pairwise Differences to an Exact Numerical Mode Formula for n Observations

Jasmin Ivankovic and ChatGPT (GPT-6)

Download research essay (PDF)

Abstract

We develop an exact algebraic representation of the statistical mode of a finite real dataset through pairwise differences and floor functions. The method encodes ordinary frequency counting; it is not a new statistical definition of mode.

Generalized construction

For observations x₁,…,xₙ, define each observation's frequency as

fᵢ = ∑ⱼ₌₁ⁿ ⌊1/(1 + |xᵢ − xⱼ|)⌋.

Set F = maxᵢ fᵢ and wᵢ = ⌊1/(1 + F − fᵢ)⌋. When the mode is unique:

M = (∑ᵢ₌₁ⁿ xᵢ wᵢ) / (∑ᵢ₌₁ⁿ wᵢ).

For ties, the exact set of modal values is {xᵢ : fᵢ = F}; averaging the tied values is not a valid substitute.

Scope

The identity is exact for finite datasets under exact numerical equality. Naive evaluation uses O(n²) comparisons. This research note is a mathematical exposition, not a peer-reviewed publication.
