# De Paritate et Phasi

A classical web reader for **De Paritate et Phasi — On Parity and Phase**, a numerical-analysis essay by Jasmin Ivankovic.

The site includes:

- an embedded 17-page PDF reader;
- direct PDF and SystemaDock Inst ZIP downloads;
- an interactive explorer for the verified identity
  `((c-b)/a)^n = 1`;
- the distinction between odd and even exponent converses;
- responsive, accessible classical typography.

## Publication

This repository is designed for GitHub Pages from the `main` branch root.
