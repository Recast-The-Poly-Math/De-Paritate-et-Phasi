Across 601 logarithmically spaced cutoffs from 1,000 to one billion, the largest sampled absolute ratio was approximately 0.69524, at x = 1,622, where the signed total was −28.

How much cancellation occurs in an arbitrary range?

Let S(x) be the published signed total through x, with the term for 1 omitted. For any inclusive interval [A, B] between 1 and one billion, compute the totals at its two endpoints as shown below. Define S(0) = 0.

Signed count in [A, B] = S(B) − S(A − 1).

The difference is exact. To compare the size of the imbalance across intervals, divide its absolute value by √L, where L = B − A + 1 counts all integer positions in the interval.

The two intervals of length 100,000 have different imbalances. The 601 original samples measured totals starting from 1. Their largest observed ratio, 0.69524, applies to those sampled cutoffs. A bound in terms of interval length that holds for every starting point would require a separate argument.

How the count works

Use only primes greater than 2. An odd integer with any repeated prime factor contributes zero. A product of k distinct odd primes contributes (−1)k. The resulting signed total is the odd Möbius sum with its initial term μ(1) = 1 removed.

The calculation sieves the small cutoffs directly. At larger cutoffs it uses the exact divisor identity below, grouping odd d that give the same quotient. Here Modd includes 1.

∑odd d ≤ x Modd(⌊x/d⌋) = 1.

The number of odd squarefree integers, together with the signed total, determines the positive and negative counts. A second computation used the ordinary summatory Möbius function and recovered the same net of −2,990 at one billion.

Reproduce the counts with C++17 
#include <cmath>
#include <cstdint>
#include <cstdlib>
#include <iomanip>
#include <iostream>
#include <set>
#include <unordered_map>
#include <vector>

class OddMobius {
  static constexpr int limit = 5'000'000;
  std::vector<int8_t> mu = std::vector<int8_t>(limit + 1);
  std::vector<int> prefix = std::vector<int>(limit + 1);
  std::unordered_map<int64_t, int64_t> cache;

public:
  OddMobius() {
    std::vector<int> least(limit + 1), primes;
    mu[1] = 1;
    for (int n = 2; n <= limit; ++n) {
      if (least[n] == 0) {
        least[n] = n;
        primes.push_back(n);
        mu[n] = -1;
      }
      for (int p : primes) {
        if (p > limit / n) break;
        least[n * p] = p;
        if (p == least[n]) break;
        mu[n * p] = -mu[n];
      }
      prefix[n] = prefix[n - 1] + (n % 2 ? mu[n] : 0);
    }
    for (auto &count : prefix) ++count;
    prefix[0] = 0;
  }

  int64_t sum(int64_t x) {
    if (x <= limit) return prefix[x];
    if (auto it = cache.find(x); it != cache.end()) return it->second;
    // Summing M_odd(floor(x/d)) over odd d gives 1 by Möbius inversion.
    int64_t total = 1;
    for (int64_t first = 3; first <= x;) {
      const auto q = x / first;
      const auto last = x / q;
      const auto odds = (last + 1) / 2 - first / 2;
      total -= odds * sum(q);
      first = ((last + 1) | 1);
    }
    return cache.emplace(x, total).first->second;
  }

  int64_t nonzero(int64_t x) const {
    int64_t total = 0;
    for (int64_t d = 1; d * d <= x; d += 2) total += mu[d] * ((x / (d * d) + 1) / 2);
    return total;
  }

  void verify() {
    for (int n : {1, 3, 9, 15, 90, 1001, 12345}) {
      int64_t expected = 0;
      for (int m = 1; m <= n; m += 2) {
        int remainder = m;
        int sign = 1;
        for (int p = 3; p * p <= remainder; p += 2) {
          if (remainder % p) continue;
          remainder /= p;
          sign = -sign;
          if (remainder % p == 0) {
            sign = 0;
            break;
          }
        }
        if (remainder > 1) sign = -sign;
        expected += sign;
      }
      if (sum(n) != expected) std::exit(1);
    }
  }
};

int main() {
  OddMobius mobius;
  mobius.verify();
  std::cout << std::fixed << std::setprecision(7);
  for (int64_t x = 1000; x <= 1'000'000'000; x *= 10) {
    const auto signed_count = mobius.sum(x);
    const auto nonzero = mobius.nonzero(x);
    const auto positive = (nonzero + signed_count) / 2 - 1;
    const auto negative = (nonzero - signed_count) / 2;
    std::cout << x << ' ' << positive << ' ' << negative << ' '
              << signed_count - 1 << ' ' << (signed_count - 1) / std::sqrt(x) << '\n';
  }
  std::set<int64_t> checkpoints;
  for (int i = 0; i <= 600; ++i) checkpoints.insert(std::llround(std::pow(10.0, 3 + i / 100.0)));
  for (int decade = 3; decade < 9; ++decade) {
    const auto lo = std::llround(std::pow(10.0, decade));
    const auto hi = 10 * lo;
    double peak = 0;
    int64_t peak_x = 0;
    for (const auto x : checkpoints) {
      if (x < lo || x >= hi) continue;
      const double scaled = std::abs(mobius.sum(x) - 1) / std::sqrt(x);
      if (scaled > peak) {
        peak = scaled;
        peak_x = x;
      }
    }
    std::cout << "Peak sample " << lo << ' ' << hi << ' ' << peak_x << ' ' << peak << '\n';
  }
}

Connection to the Riemann hypothesis

The simulation measures cancellation at finite cutoffs. A bound of order x1/2+ε for the odd Möbius sum, for every ε > 0 as x tends to infinity, would establish the Riemann hypothesis. Partial summation would give a holomorphic reciprocal zeta function for Re(s) > 1/2. Removing the Euler factor at 2 leaves the zero-free question in that half-plane unchanged.

The sampled cutoffs show strong cancellation on the tested range. The bound for arbitrarily large x remains open.

See Clay Mathematics Institute’s statement of the hypothesis and the summatory Möbius criterion discussed by Hu and coauthors.
