48-key symbolic association game

Greek Keysupper and lower Greek letters as memory prompts

Greek Keys cycles through all 24 uppercase and 24 lowercase Greek letters, gives each one a suggested response, lets you write your own association, and exports the completed session as a UTF-8 text file.

Open Render deployment

The exact live Greek Keys Render URL will be inserted here once Render assigns its unique hostname.

Game structure

Uppercase Keys

Each uppercase symbol carries a broad conceptual association such as beginning, transformation, perspective, summation, state, or completion.

Lowercase Keys

Each lowercase symbol carries a practical response such as start the task, change one variable, check the structure, or finish and review.

Suggested Responses

Every key includes a suggested response and a button that can copy that suggestion into the editable answer field.

UTF-8 Export

The completed 48-key session is exported as greek_keys.txt with UTF-8 handling so Greek symbols remain intact.
